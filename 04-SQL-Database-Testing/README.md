# SQL & Database Testing Project – MySQL

## 1. Project Overview

This project demonstrates practical SQL and database testing skills using MySQL.

The project focuses on validating database operations, retrieving and verifying data, executing SQL queries, analysing query results, and identifying data-related defects.

It forms part of my QA portfolio and demonstrates my understanding of database testing concepts and SQL-based validation.

## 2. Project Objectives

- Practise SQL queries for database validation.
- Validate data retrieval and accuracy.
- Verify database records against expected results.
- Identify data inconsistencies and potential defects.
- Execute structured database test scenarios and test cases.
- Document test results and defects.
- Maintain organised SQL testing documentation.

## 4. Testing Scope

The project covers SQL and database testing activities documented in the project files.

The testing focuses on:

- SQL query execution and result validation.
- Database record retrieval.
- Data accuracy and consistency checks.
- Validation of database operations.
- Verification of expected and actual results.
- Identification and documentation of defects.

## 5. Testing Approach

The project follows a structured testing workflow:

1. Review the project documentation and database setup.
2. Understand the database structure and available data.
3. Identify database testing scenarios.
4. Prepare test cases with test steps and expected results.
5. Execute SQL queries using MySQL.
6. Compare actual query results with expected results.
7. Record test execution outcomes.
8. Document defects and supporting evidence.
9. Prepare the test execution summary.
